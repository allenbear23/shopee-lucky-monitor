## 二、機會怎麼來（確定，來自 Template 設定）

```json
{"daily_chance":{"limit":1},"share_chance":{"limit":3,"share_incr":1},
 "order_chance":{"limit":99,"order_incr":1,"order_pay":100}}
```

- **免費**：每人每天 1 次（每天 00:00 重置，不累積）
- **分享**：每天最多 3 次，每次分享 +1 次（所以名義上「分享 3 次」= 每天最多 4 抽）
- **下單**：在該賣場**消費滿 NT$100** +1 次，每天最多 99 次（活動名的「立即下單」就是這個鉤子）
- **摃龜/冷卻**：UI 文案有「休息一下再抽獎，會有更好的中獎機率」→ 連抽有冷卻/頻率限制（`too_frequent` 錯誤訊號存在）

「中獎翻倍」在資料裡**找不到倍率欄位**，實作上就是「分享 3 次多拿 3 次機會」，屬行銷文案。（推論）

## 六、期望值 → 值得玩嗎？

前提：拿不到摃龜率，以下只能算「**中獎時**的條件期望值（面額）」：約 **NT$3.3 / 中獎**（1 蝦幣 0.96 + 30 券 0.5 + 50 券 0.4 + 100 券 1.3）。

- 每帳每天免費 4 抽。若摃龜率 50% → 期望約 NT$6.6/天/帳；摃龜率 90% → 約 NT$1.3/天/帳。
- 券要**在該賣場消費**才兌現，不買東西就等於 0；蝦幣也只能折抵該賣場、單筆上限 25%。
- 玩法建議：**免費 4 抽 + 本來就會買的生活超市訂單（滿百一單+1抽）**值得；為抽獎刻意下單不划算。
- 活動條款明文禁止：多帳號、惡意程式/干擾抽獎公平性 → 自動多開帳會被整批砍（規則第 1 條）。
